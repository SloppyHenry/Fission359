# App-Icon

Das aktuelle Icon ist ein **Platzhalter** (Würfel in der Akzentfarbe aus `docs/08-gestaltung.md`).
Es wird von `scripts/tools/make_icons.py` erzeugt; die Dateien hier sind das eingecheckte Ergebnis.
Ein echtes Icon ersetzt `make_icons.py` bzw. die Dateien in `png/` und die SVG-Datei.

- `io.github.sloppyhenry.Fission359.svg` – Linux (skalierbar)
- `png/icon-<Größe>.png` – Linux-Größen und Grundlage für das macOS-`.icns` (wird beim Bauen mit `iconutil` erzeugt)
- `dmg-background*.png` – Hintergrund des Mac-Installationsfensters
